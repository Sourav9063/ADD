# Repository Memory

- `AGENTS.md` is the canonical source for repository agent guidance.
- Only `AGENTS.md` is copied into target projects; this repository's `agents/` content exists to curate that file and is not distributed.
- The `AGENTS.md` block in `README.md` is generated by `.github/workflows/embed-agents.yml`; do not update it manually.
- Preserve the repository's lightweight, judgment-driven, vendor-neutral SDD model. Add mandatory workflow machinery only after an explicit repository-wide decision.
